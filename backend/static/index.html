Three questions.
Every request.

Other routers ask which cloud model to use. GreenRoute first asks whether the request needs to leave your device at all.

01

What is it?

A rules engine labels the task (Q&A, summary, code, essay, image…) and scores its complexity from 0 to 1 using length and cues like "detailed" or "1500 words".

02

Can this device do it?

It checks the local model's size, free memory, battery and input length. A 1B model gets a lower complexity limit than a 3B one.

03

Where should it run?

On-device by default. The cloud only when a check fails — and the failed check becomes the reason you see.

The checks, in order

  1. Task type — image generation can't run on a local text model.
  2. Device mode — a low-spec device would be too slow.
  3. Battery — under 20% and unplugged, offload to save power.
  4. Input length — long documents are slow on laptop CPUs.
  5. Confidence — if the request can't be classified, play it safe.
  6. Complexity — the score must be within the local model's limit.
  7. Memory — enough free RAM to load the model.

The honest math.

Each answer is compared with the cloud baseline. Local isn't free — it costs your device's electricity — so savings are net.
